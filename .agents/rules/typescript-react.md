# React + TypeScript Rules

- Use strict TypeScript.
- Avoid `any`; use proper types, unknown, discriminated unions or generics.
- Prefer functional React components.
- Keep components focused.
- Do not put database calls directly into presentational components.
- Use stable keys and avoid array-index keys for dynamic collections.
- Handle loading, empty, error and success states.
- Keep forms validated.
- Avoid unnecessary re-renders and duplicated state.
- Follow existing naming conventions.
