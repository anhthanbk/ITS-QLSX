# Database Change Skill

1. Inspect the existing schema.
2. Identify affected tables, foreign keys, indexes, RLS and application queries.
3. Propose the migration before executing it.
4. Keep migrations backward-compatible when practical.
5. Add or update RLS policies.
6. Update generated/application types if the project uses them.
7. Update data-access code.
8. Test reads, writes and permissions.
9. Review query performance and indexes.
10. Run the full verification suite.
