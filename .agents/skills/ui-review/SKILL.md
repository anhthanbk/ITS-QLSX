# UI Review Skill

1. Open the requested screen in the browser.
2. Test realistic data states: loading, empty, normal, long text and errors.
3. Check hierarchy, spacing, typography, controls and table usability.
4. Check desktop and narrow/mobile layouts.
5. Check keyboard focus and obvious accessibility problems.
6. Record defects before changing code.
7. Apply only approved/relevant UI changes.
8. Re-test the same flows.
9. Confirm no business logic or database behavior was unintentionally changed.
