# Bug Fix Skill

1. Reproduce the issue.
2. Capture the exact error and affected flow.
3. Trace the root cause rather than treating the symptom.
4. Inspect related state, API/database calls and UI lifecycle.
5. Implement the smallest safe fix.
6. Add or update regression coverage where practical.
7. Run typecheck/lint/tests/build.
8. Reproduce the original scenario again in the browser.
9. Check that unrelated functionality still works.
10. Report root cause, fix and verification.
