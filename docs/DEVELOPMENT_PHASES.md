# Development Phases

## Phase 0 — Foundation
Repository, package manager, lint, formatting, environment handling, rules, skills, MCP.

## Phase 1 — Architecture
Application shell, folder structure, routing, design system and error/loading conventions.

## Phase 2 — Database
Schema, migrations, relationships, indexes, RLS, seed data and generated types.

## Phase 3 — Identity
Authentication, roles, permissions, user profile, protected routes and audit logging.

## Phase 4 — Core UI
Sidebar, header, dashboard shell, tables, forms, dialogs, notifications and responsive behavior.

## Phase 5 — Master Data
Employees, departments, positions, products, materials, warehouses, machines, customers and suppliers.

## Phase 6 — Operations
Production, warehouse, maintenance, mining, sales/order/shipping workflows.

## Phase 7 — Reports
KPI, OEE, inventory, production and management dashboards.

## Phase 8 — Quality
Regression tests, Playwright, performance, egress, security and accessibility.

## Phase 9 — Release
CI/CD, Vercel, domain, production environment, database migration and production browser verification.
